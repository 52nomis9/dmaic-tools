兑换码生成 / 校验 / 库存核对。本页面在本地运行，不联网、不上传任何数据。

生成的兑换码必须同时用于两处：① 粘贴到爱发电商品的「高级选项 → 多行随机码」；② 更新到 dmaic-data 私有仓库的 codes.csv（保持全部历史码都在文件内）。

① 批量生成支付兑换码

算法：数据码 = MOD(种子×987654321+123456789, 9000000000)+1000000000（10 位），校验码 = 98 − MOD(数据码×100, 97)（2 位），共 12 位；校验规则 (前10位×100+后2位) MOD 97 = 1。

② 校验兑换码（仅校验数值规则）

仅校验数值规则是否有效；是否已被使用需在下方「库存核对」或注册库中查询。

说明：GitHub 会阻止把明文/base64 令牌提交进仓库（密钥扫描推送保护），因此 config.js 中的令牌以「反转 base64」编码存储。轮换令牌步骤：① 在 GitHub 创建新令牌（仅 dmaic-data、Contents 读写）→ ② 此处生成编码串 → ③ 编辑 dmaic-tools 仓库的 config.js，替换 atob('...') 内的字符串 → ④ Commit → ⑤ 删除旧令牌。
