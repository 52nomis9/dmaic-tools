# DMAIC Tools 账号注册与激活系统（卖家手册）

基于 GitHub 的轻量级注册发码系统：买家在爱发电购买商品 → 获得支付兑换码 → 在注册页填写信息 → 获取 12 位一次性注册激活码。

## 一、系统组成

| 组成 | 位置 | 作用 |
|---|---|---|
| 注册页（公开仓库 `dmaic-tools`） | GitHub Pages：`https://52nomis9.github.io/dmaic-tools/` | 买家填写注册信息、生成激活码 |
| 数据库（私有仓库 `dmaic-data`） | 仅卖家可见 | `codes.csv` 兑换码码池 + `registrations.csv` 注册库 |
| 卖家工具 | `https://52nomis9.github.io/dmaic-tools/generator.html`（本地打开亦可） | 批量生成兑换码 / 校验 / 库存核对 |
| 爱发电商品配置 | afdian.net 卖家后台 | 商品「高级选项」多行随机码，买家购买时随机发放一个 |

页面文件说明：

| 文件 | 职责 |
|---|---|
| `index.html` | 注册页（上半部分账号注册 + 下半部分软件功能介绍，介绍区后续补充） |
| `core.js` | 核心算法：兑换码生成校验、激活密钥生成、CSV 读写、注册流程 |
| `config.js` | 站点配置（GitHub 用户名 / 数据仓库名 / 访问令牌） |
| `generator.html` | 卖家工具（不联网、纯本地计算） |

## 二、核心规则

**支付兑换码（12 位数字）**
- 数据码（10 位）= MOD(种子×987654321+123456789, 9000000000) + 1000000000
- 校验码（2 位）= 98 − MOD(数据码×100, 97)
- 校验规则：取前 10 位 D 与后 2 位 C，若 (D×100+C) MOD 97 = 1 则数值有效
- 注册时要求：数值有效 **且** 存在于码池 **且** 未被使用（一次性）

**注册激活码（12 位字母数字混合）**
- 注册序号从 1901 起依次分配
- ① = 注册序号后四位，② = 账户名后四位，③ = BIOS 整机序列号后四位
- 按 ①②③①②③①②③①②③ 逐位交叉拼接
- BIOS 序列号为空或 `To be filled by O.E.M.` 时按 `TBFBYOEM` 登记
- 示例：序号 1901、账号 `DMAICuser`、BIOS `PF3XYZ9K` → 激活码 `1uY9sZ0e91rK`

**注册库 registrations.csv 各列**
`注册序号,账号名,支付兑换码,日期序列,BIOS序列号,激活密钥,联系电话,联系邮箱,注册时间`

## 三、日常运营：补充兑换码

1. 打开 `generator.html` → 输入数量（如 100）→「生成」→「下载 codes.csv」
2. **同一批码必须同时用于两处**：
   - 爱发电卖家后台 → 商品编辑 → 高级选项 → 多行随机码：粘贴生成的码（每行一个）。⚠️ 建议以「追加」方式补充，勿删除尚未售出的旧码
   - GitHub 私有仓库 `dmaic-data` → `codes.csv` → 铅笔编辑 → 用新文件内容**整体替换**（保留全部历史码）→ Commit
3. 用「库存核对」随时查看剩余可用数量（粘贴 codes.csv 与 registrations.csv 全文）

## 四、常见操作

**查询买家激活码**：打开 `dmaic-data` 仓库 `registrations.csv`，按账号名/兑换码/电话搜索。

**买家找回激活码**：registrations.csv 中按账号名查「激活密钥」列即可。

**轮换数据令牌**（如怀疑泄露）：GitHub → Settings → Developer settings → Fine-grained tokens → 删除旧令牌并新建（仅授权 dmaic-data、Contents 读写）→ 编辑公开仓库 `dmaic-tools/config.js` 替换 token → Commit。

**修改功能介绍区**：编辑公开仓库 `dmaic-tools/index.html` 的 `<section id="features">` 区域。

## 五、爱发电商品设置（首次）

1. 爱发电卖家后台 → 创建/编辑商品 → 价格方案
2. 添加「高级选项」（可设置选项/自定义表单），类型选择**多行文本随机发放**
3. 将 generator.html 生成的一批兑换码粘贴进去（每行一个）
4. 买家下单后，爱发电会从多行随机码中随机取一个发放给买家（订单详情/私信可见）
5. 确保同一批码也已更新到 `dmaic-data/codes.csv`

## 六、注意事项

- **令牌安全**：`config.js` 中的 token 嵌在公开页面内（这是 GitHub 静态站做读写的标准做法），权限已收敛为仅 `dmaic-data` 仓库 Contents 读写；如被滥用可随时轮换，数据可用 git 历史恢复
- **大陆访问**：`github.io` 与 `api.github.com` 在中国大陆部分网络环境访问不稳定，买家若无法打开页面或提交失败，建议更换网络；后续可绑定自定义域名缓解
- **并发**：两人同时注册时系统自动重试避免序号冲突；极端情况下提示「系统繁忙」重新提交即可
- **兑换码一次性**：重复提交同一兑换码会被拒绝（以注册库为准）
