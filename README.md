# DMAIC Tools 账号注册与激活系统（卖家手册）

基于 GitHub 的轻量级注册发码系统：买家在爱发电购买商品 → 获得支付兑换码 → 在注册页填写信息 → 获取 16 位一次性注册激活码；支持自助找回激活码与用户反馈。

## 一、系统组成

| 组成                      | 位置                                                              | 作用                                          |
| ----------------------- | --------------------------------------------------------------- | ------------------------------------------- |
| 注册页（公开仓库 `dmaic-tools`） | GitHub Pages：`https://52nomis9.github.io/dmaic-tools/`          | 买家填写注册信息、生成激活码；找回激活码；提交用户反馈；页面底部可读取/清空反馈 |
| 数据库（私有仓库 `dmaic-data`）  | 仅卖家可见                                                           | `codes.csv` 兑换码码池 + `registrations.csv` 注册库 + `feedback.json` 用户反馈 |
| 卖家工具                    | `https://52nomis9.github.io/dmaic-tools/generator.html`（本地打开亦可） | 批量生成兑换码 / 校验 / 库存核对（支持自动读取）/ 注册库查询         |
| 爱发电商品配置                 | afdian.net 卖家后台                                                 | 商品「高级选项」多行随机码，买家购买时随机发放一个                   |

页面文件说明：

| 文件               | 职责                                 |
| ---------------- | ---------------------------------- |
| `index.html`     | 注册页（买家仅需填写账号/兑换码/电话/邮箱；账号名即时格式校验与查重；BIOS/计算机名/日期序列自动采集、买家不可见；「生成注册激活码」左下「找回激活码」、右下「用户反馈」；下半部分为软件功能介绍，卡片支持悬停动效与点击查看详情；页面最下方为反馈记录读取/清空区） |
| `core.js`        | 核心算法：兑换码生成校验、激活密钥生成、CSV 读写、注册流程、找回激活码、用户反馈读写    |
| `config.js`      | 站点配置（GitHub 用户名 / 数据仓库名 / 访问令牌，令牌为反转 base64 编码）    |
| `generator.html` | 卖家工具（①~② 本地计算；③ 库存核对可一键自动读取私有库两个文件；④ 令牌编码；⑤ 注册库查询联网读取私有数据库）                    |

> **机器信息自动采集**：注册页从 URL 参数静默读取机器信息（买家不可见，仅存入数据库）——`?sn=<BIOS整机序列号>` 与 `?cn=<计算机名>`。DMAIC Tools 桌面软件的注册入口应以 `https://52nomis9.github.io/dmaic-tools/?sn=<整机序列号>&cn=<计算机名>` 打开注册页，即可自动完成机器绑定；买家直接打开链接（无参数）时 BIOS 按 `TBFBYOEM`、计算机名按 `PCNAME` 兜底登记。
>
> **账号名查重**：买家录入账号名后页面即时校验格式（5~9 位英文字母，区分大小写，红字提示错误）并联网检索是否已被注册；提交时服务端再次兜底校验，重复账号不会写入数据库。

## 二、核心规则

**支付兑换码（12 位数字）**

- 数据码（10 位）= MOD(种子×987654321+123456789, 9000000000) + 1000000000

- 校验码（2 位）= 98 − MOD(数据码×100, 97)

- 校验规则：取前 10 位 D 与后 2 位 C，若 (D×100+C) MOD 97 = 1 则数值有效

- 注册时要求：数值有效 **且** 存在于码池 **且** 未被使用（一次性）

**注册激活码（16 位字母数字混合）**

- 注册序号从 1901 起依次分配

- ① = 注册序号后四位，② = 日期序列前四位（年份），③ = BIOS 序列号后四位，④ = 计算机名后四位（③④ 的连字符统一不计入位数）

- 按 ①②③④①②③④①②③④①②③④ 逐位交叉拼接

- BIOS 序列号为空或 `To be filled by O.E.M.` 时按 `TBFBYOEM` 登记；计算机名为空时按 `PCNAME` 登记，不足 4 位左补 0

- 示例：序号 1901、日期序列 20260903、BIOS `PF3XYZ9K`、计算机名 `DESKTOP-ABC123` → 激活码 `12YC90Z1029216K3`

- 成功弹窗只显示激活码与绑定账号，序号/日期/BIOS/计算机名均不显示（保密）

**找回激活码（注册页左下按钮）**

- 条件：账号名存在，且**联系电话与联系邮箱均**与注册库一致（任一不符即弹窗报错）

- 频率：距该账号上次「激活时间」满一年及以上才可找回（每个账号一年一次）；首次注册时激活时间 = 注册时间

- 动作：按**当前日期序列 + 当前页面采集的 BIOS / 计算机名**重新计算激活码，覆盖该账号行的日期序列、BIOS、计算机名、激活密钥、激活时间（注册时间与其余信息不变）

- 用途：换电脑后旧激活码失效时，买家可自助重置绑定新机器

**用户反馈（注册页右下按钮）**

- 条件：账号名存在，且联系电话 / 联系邮箱**至少一项**与注册库一致（均不符才弹窗报错）

- 内容：文本框最多 300 字

- 存储：提交后追加写入私有库 `feedback.json`（JSON 数组），每条含账号名、反馈时间、反馈电脑的 BIOS 序列号、计算机名、反馈内容

- 管理：注册页最下方「用户反馈记录」区可一键读取全部反馈、一键清空重置（写回空数组）

**注册库 registrations.csv 各列（11 列）**
`注册序号,账号名,支付兑换码,日期序列,BIOS序列号,计算机名,激活密钥,联系电话,联系邮箱,注册时间,激活时间`

- 首次注册：激活时间 = 注册时间；找回重置后：激活时间 = 重置时间（注册时间不变）

- 旧版 10 列数据（无激活时间列）在新注册/找回写入时自动迁移为 11 列，旧行激活时间按注册时间回填

## 三、日常运营：补充兑换码

1. 打开 `generator.html` → 输入数量（如 100）→「生成」→「下载 codes.csv」
2. **同一批码必须同时用于两处**：

   - 爱发电卖家后台 → 商品编辑 → 高级选项 → 多行随机码：粘贴生成的码（每行一个）。⚠️ 建议以「追加」方式补充，勿删除尚未售出的旧码

   - GitHub 私有仓库 `dmaic-data` → `codes.csv` → 铅笔编辑 → 用新文件内容**整体替换**（保留全部历史码）→ Commit
3. 用「库存核对」随时查看剩余可用数量：点击两个「↻ 自动读取」按钮直接从私有仓库拉取 codes.csv 与 registrations.csv（也可手动粘贴全文）

## 四、常见操作

**查询买家激活码**：打开 `dmaic-data` 仓库 `registrations.csv`，按账号名/兑换码/电话搜索；或用 generator.html「⑤ 注册库查询」。

**查看用户反馈**：注册页最下方「用户反馈记录」→「读取反馈记录」；或直接打开 `dmaic-data` 仓库的 `feedback.json`。处理完毕后可点「清空重置反馈」。

**买家找回激活码**：买家在注册页填账号名 + 联系电话 + 联系邮箱（均须与注册库一致），点「找回激活码」自助重置（一年一次）；卖家亦可在 registrations.csv 中按账号名查「激活密钥」列告知买家。

**轮换数据令牌**（如怀疑泄露）：

1. GitHub → Settings → Developer settings → Fine-grained tokens → 新建令牌（仅授权 dmaic-data、Contents 读写，有效期选最长）
2. 打开 `generator.html` → 「④ 令牌编码」→ 粘贴新令牌 → 生成编码串
3. 编辑公开仓库 `dmaic-tools/config.js` → 替换 `atob('...')` 引号内的字符串 → Commit
4. 回到令牌管理页删除旧令牌

> 注意：GitHub 密钥扫描会阻止把明文/base64 形式的令牌提交进仓库，因此 config.js 里的令牌以「反转 base64」编码存储，轮换时务必使用 generator.html 的编码工具。

**修改功能介绍区**：编辑公开仓库 `dmaic-tools/index.html` 的 `<section id="features">` 区域。

## 五、爱发电商品设置（首次）

1. 爱发电卖家后台 → 创建/编辑商品 → 价格方案
2. 添加「高级选项」（可设置选项/自定义表单），类型选择**多行文本随机发放**
3. 将 generator.html 生成的一批兑换码粘贴进去（每行一个）
4. 买家下单后，爱发电会从多行随机码中随机取一个发放给买家（订单详情/私信可见）
5. 确保同一批码也已更新到 `dmaic-data/codes.csv`

## 六、注意事项

- **令牌安全**：`config.js` 中的 token 嵌在公开页面内（这是 GitHub 静态站做读写的标准做法），权限已收敛为仅 `dmaic-data` 仓库 Contents 读写；如被滥用可随时轮换，数据可用 git 历史恢复。注册库与 feedback.json 均存于该私有仓库，与注册数据同一访问模型

- **大陆访问**：`github.io` 与 `api.github.com` 在中国大陆部分网络环境访问不稳定，买家若无法打开页面或提交失败，建议更换网络；后续可绑定自定义域名缓解

- **并发**：两人同时注册时系统自动重试避免序号冲突；找回激活码与反馈提交同样带冲突重试；极端情况下提示「系统繁忙」重新提交即可

- **兑换码一次性**：重复提交同一兑换码会被拒绝（以注册库为准）

- **找回一年一次**：以注册库「激活时间」列为准（首次注册 = 注册时间，找回后 = 重置时间）；改回更短周期需调整 core.js 中 `recover` 的判断
